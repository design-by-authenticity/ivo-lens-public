# Contributing and critical review

The I·V·O Lens benefits from criticism that identifies a specific structural error, unsupported assumption, scale mismatch, domain overreach, dependency failure, or ambiguous operator assignment.

## Useful contributions

Useful reports include:

- an O/V/I classification that appears wrong;
- a physical interaction that has been mistaken for observer-dependent interpretation;
- a claim that holds only at one scale or observer position but is generalized further;
- a hidden assumption that changes the analysis outcome;
- a module that produces decorative output without a non-trivial finding;
- inconsistent terminology between files or versions;
- a domain where the framework should refuse synthesis or declare itself inapplicable;
- a reproducible example where two models apply the same prompt differently.

## Suggested issue format

Please include:

1. **Object or domain** — what was analyzed?
2. **Version** — which prompt or document version was used?
3. **Observed output** — what did the lens or model produce?
4. **Suspected failure** — what appears structurally wrong?
5. **Proposed test** — what evidence or comparison could confirm or reject the criticism?
6. **Scope** — is the problem local to one example or likely to affect the instrument more broadly?

## Boundaries

Do not submit:

- identifiable clinical or personal case material;
- confidential organizational information;
- API keys or credentials;
- copyrighted material you do not have permission to share;
- model-generated claims presented as established facts without verification.

## Changes to canonical material

Public suggestions do not directly redefine the canonical instrument. Accepted changes are first evaluated in the private canonical environment, recorded with provenance, and then released publicly when stable enough.

This protects the project from developing multiple conflicting sources of truth.
