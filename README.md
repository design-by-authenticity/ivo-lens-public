## What this repository is

This is the public research and release layer of the I·V·O Lens, developed by **Ivo van der Wal** under **Design by Authenticity**.

It is intentionally separate from the private canonical development environment. The private repository holds working hypotheses, experimental mutations, unpublished observations, and internal governance.
