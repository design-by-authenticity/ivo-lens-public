# Visual assets

This directory will contain approved public diagrams and visual representations of the I·V·O Lens.

## Planned first asset

The canonical research visual showing:

- O as possibility space;
- V as relational change;
- I as observation / distinction;
- the OVI generative direction;
- the IVO analytical direction;
- frame-to-frame development where relevant.

## Visual release rule

A visual is added only when its labels, topology, directionality, notation, and version match the private canonical source.

Exploratory renders, parameter experiments, abandoned layouts, and mutation studies remain in the private visual work environment until selected for public release.

Every public visual should include or be accompanied by:

- title;
- version;
- date;
- creator attribution;
- license;
- alt text or a textual explanation;
- status: stable, experimental, frozen, or archived.
