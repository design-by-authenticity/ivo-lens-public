# v4.0 license audit

Audit date: 19 August 2026  
Scope: pre-release preparation for **I·V·O Lens Prompt v4.0 — Canonical Reference Version**

## Result

No conflicting grant of rights was found in the audited release materials. No legal terms were invented or broadened during release preparation.

| Area | Audited position |

| Non-commercial use | Permitted under CC BY-NC-SA 4.0 conditions |

| Adaptation/derivatives | Permitted for non-commercial use with attribution, indication of changes, and ShareAlike |
| Attribution | Ivo van der Wal, Design by Authenticity, and the I·V·O Lens must be credited |
| Commercial application | Not granted by the repository license; separate written permission or agreement is required |
| Commercial licenses | Available separately through Design by Authenticity |

## Website comparison

The audited website statements identify CC BY-NC-SA 4.0 for the open layer and state that commercial applications or commercial use require a separate license. This is consistent with `LICENSE.md`; no broader commercial permission was found.

The readable canonical page does not itself add a conflicting rights statement. The repository license and canonical prompt header remain the explicit rights references.
