## Description
The I·V·O Lens is a domain-independent framework for structural analysis using three functional operators within an explicitly stated scope: O — Structured Possibility, V — Instantiated Relation, and I — Situated Selectivity.

Version 4.1 retains the frozen v4.0 operator semantics and adds epistemic safeguards developed through reproducible cross-model failure analysis and a controlled Project Hessdalen regression across Claude, ChatGPT, and Gemini. The release adds shared evidence-provenance and claim-status vocabularies; observation → event → class → membership → mechanism separation; negative-claim and unknown-state safeguards; hypothesized-mechanism gating; evidential-dependency controls; causal-status discipline; and claim-level reliability constraints.

Successful regression supports the tested failure modes and conditions only; it does not establish universal validity, empirical validation, completeness, or immunity to model bias.
