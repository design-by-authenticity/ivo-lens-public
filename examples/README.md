# Worked examples

This directory will contain examples that show what the I·V·O Lens does in practice without presenting model output as proof of validity.

## Planned example types

- a short personal or micro-scale analysis;
- a team or organizational analysis;
- a measurement/intervention case;
- a multi-perspective case;
- a case in which the lens refuses synthesis;
- an I·V·O Design example;
- an I·V·O Cycle example.

## Example standard

Each example should state:

- the input object;
- the instrument version;
- the model or human process used;
- relevant assumptions;
- what is direct observation, interpretation, or speculation;
- known limitations;
- whether the example is illustrative, stress-tested, pilot-derived, or research data.

No identifiable client, patient, employee, or private organizational case material may be published here.
