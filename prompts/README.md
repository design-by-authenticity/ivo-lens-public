# Prompts

This directory will contain stable public prompt releases derived from the private canonical instrument.

## Planned core instruments

- **I·V·O Analysis Prompt** — reconstructs a structure and reads it analytically.
- **I·V·O Design Prompt** — uses the operator structure to generate or redesign a system, object, service, or environment.
- **I·V·O Cycle Prompt** — analyzes frame-to-frame development rather than treating the object as static.

## Release rule

A prompt is added here only when:

- its canonical source has been identified;
- version and status are explicit;
- modules and dependencies are internally consistent;
- the public file is not already superseded;
- usage boundaries and license are included;
- it has been checked against the corresponding Zenodo record.

## Current baseline

The validation-study methodology is frozen at v3.2.1 as part of Baseline 1.0. The complete public prompt files are being extracted and checked before release.

Until that extraction is complete, use the archived Zenodo material as the formal published reference rather than reconstructing a prompt from summaries in this repository.
