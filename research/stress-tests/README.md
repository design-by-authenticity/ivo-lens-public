# I·V·O Lens stress-test provenance

Status: **Research / Provenance — Not Canonical Prompt Content**

This location is reserved for the falsification and validation history behind the public canonical definitions. It complements, but never modifies or replaces, the frozen canonical prompt.

Future stress-test dossiers should document:

- which hypotheses or operator boundaries were attacked;
- which counterexamples and domains were used;
- which rules failed or produced overreach;
- which canonical changes followed from those failures;
- which tests the final v4.0 prompt survived;
- test dates, prompt identities, model/tool versions, inputs, outputs, and interpretation decisions where publication rights permit;
- negative findings, unresolved cases, and limitations.

RC1–RC4 are preserved separately under [`../../prompts/development-history/v4.0/`](../../prompts/development-history/v4.0/) as release-candidate provenance. They are not empirical validation results and are not canonical versions.

The historical Baseline 1.0 package remains under [`../validation/baseline-1.0/`](../validation/baseline-1.0/) and is not moved or rewritten. A frozen or stress-tested prompt is not automatically an empirically validated prompt.
