# I·V·O I-POSITION TEST PROTOCOL v0.1

Status: Experimental  
Purpose: Test-only execution protocol  
Canonical baseline: I·V·O Lens Prompt v4.1  
Semantics of O and V: unchanged  
Status of I-position model: experimental, non-canonical

## Purpose

This protocol tests whether explicitly distinguishing:

1. situated observer position; and
2. evidenced selective function

improves I·V·O analysis without weakening the epistemic safeguards of canonical v4.1.

Do not treat this protocol as a semantic revision of the canonical Lens.

Where this protocol conflicts with v4.1 safeguards, v4.1 governs.

---

# Experimental distinction

## I-position

An I-position is a situated observer position within the stated analytical scope.

It identifies a materially relevant position from which some part of the system can be accessed, registered, encountered, distinguished, rendered relevant, or remain outside access.

An I-position does not by itself establish an I-function.

An I-position does not require:
- human consciousness;
- agency;
- intention;
- free will;
- biological status;
- explicit criteria;
- unpredictability.

Possible carriers may include, where analytically warranted:
- person;
- group;
- organisation;
- institution;
- organism;
- sensor;
- apparatus;
- algorithm;
- technical subsystem;
- physical system;
- another materially relevant situated observer position.

Do not infer an observer position merely because an entity exists in the system.

A position must materially alter access, visibility, exclusion, reachability, registration, distinction, or appraisal.

---

## I-function

An I-function is an evidenced selective function associated with an I-position.

Canonical v4.1 safeguards remain fully active.

An I-function may be assigned only when:

1. reconstructed O applied to instantiated V leaves more than one continuation structurally open at the relevant selection point; and
2. positive evidence supports a selective step contributing to which continuation becomes instantiated.

Epistemic uncertainty is not structural openness.

Unexplained is not I.

Selective coupling is not sufficient for I.

Filtering, thresholding, weighting, criteria, memory, adaptation, basis-selection, representation, separation, or response do not establish I by themselves.

If no positive evidence for an I-function exists, retain the I-position where analytically useful and mark:

`FUNCTION UNRESOLVED`

Do not convert missing evidence into:

`NO I`

unless O + V adequately reconstruct the relevant continuation and the negative claim is supported under the canonical v4.1 safeguard.

---

# Core distinction

Always distinguish:

`POSITION`

from:

`FUNCTION`

A position can be established while its selective function remains unresolved.

Example:

`I₁ position: ESTABLISHED`

`I₁ function: UNRESOLVED`

This is a valid analytical result.

---

# Anti-proliferation rule

Do not create I-positions merely because multiple actors, entities, objects, or subsystems exist.

Introduce a separate I-position only when its situated position materially changes one or more of:

- access to O;
- access to V;
- visibility;
- exclusion;
- reachability;
- registration;
- relevance;
- appraisal;
- capacity to affect what becomes accessible to another position.

## Remove-and-compare test

For every candidate I-position ask:

> If this position is removed from the reconstruction, do we lose analytically relevant information about access, visibility, exclusion, reachability, registration, relevance, or appraisal?

If no:

Do not represent the position separately.

If yes:

Retain the position.

Do not multiply positions without analytical consequence.

# Analysis procedure

## Step 0 — Scope

State:

- analytical object;
- system boundary;
- scale;
- dominant analytical direction;
- source base.

Do not assume an observer must exist inside the selected system boundary.

---

## Step 1 — Candidate I-position scan

Identify candidate materially relevant observer positions evident from the supplied case.

Do not yet assign selective functions.

For each candidate state briefly:

- carrier / position;
- location within or relative to the system boundary;
- apparent access;
- apparent non-access;
- why the position may materially change the reconstruction.

Apply the remove-and-compare test.

Discard trivial or redundant positions.

---

## Step 2 — Reconstruct O

Apply canonical v4.1.

Reconstruct Structured Possibility independently of the candidate I-positions.

For each retained I-position, then ask:

- which O-fields are accessible?
- which O-fields are inaccessible?
- which O-fields are only inferred rather than directly accessible?
- which possibilities are formally available but functionally unreachable from this position?

Do not infer non-existence from non-access.

---

## Step 3 — Reconstruct V

Apply canonical v4.1.

Identify actually instantiated relations.

For each retained I-position ask:

- which V-relations are accessible?
- which V-relations are directly participated in?
- which V-relations are only reported or inferred?
- which relations remain outside access?
- does differential access risk being mistaken for differential existence?

Movement is not V.

Possible relation is not V.

Access to a relation is not evidence that the position selectively produced that relation.

---

## Step 4 — Position map

For each retained I-position construct:

### Iₙ — POSITION

**Carrier / position:**  
**Scope:**  
**Position status:** ESTABLISHED / SUPPORTED / UNRESOLVED

**Accessible O:**  
**Inaccessible / outside-view O:**  

**Accessible V:**  
**V outside access:**  

**Visible / registered:**  
**Relevant from this position:**  
**Excluded / ignored:**  
**Unknown / outside view:**  

**Blind spot:**  
Only state a blind spot when supported.  
Do not invent hidden information merely to complete the structure.

**Analytical consequence of this position:**  
State what is visible only because this position was represented separately.

---

## Step 5 — I-function test

For every retained I-position, separately evaluate whether an I-function is established.

### 5.1 Structural openness

At the relevant selection point:

- identify the candidate continuations;
- state whether more than one continuation remains structurally open under the explicit O/V reconstruction;
- distinguish structural openness from missing analyst knowledge.

If apparent openness could be explained by missing O/V knowledge:

`FUNCTION UNRESOLVED`

Do not continue to an established I-function.

### 5.2 Positive evidence

Identify positive evidence for the selective step itself.

The evidence must not merely be inferred from the final outcome.

Useful evidence may include:
- selection trace distinct from outcome;
- materially equivalent reconstructed states with different selections;
- counterfactual intervention on the selective step;
- other domain-appropriate evidence that independently establishes selective contribution.

If absent:

`FUNCTION UNRESOLVED`

### 5.3 O/V-only challenge

Construct the strongest O/V-only reconstruction of the same phenomenon.

Ask:

> What independently relevant structural information is lost if I is removed?

If nothing is lost:

`I-FUNCTION NOT REQUIRED`

If relevant information is lost and the canonical evidence conditions are met:

`I-FUNCTION ESTABLISHED`

If evidence is insufficient:

`FUNCTION UNRESOLVED`

### 5.4 Revocation condition

For every established I-function state:

- what added O/V evidence at the same relevant scope and resolution would weaken or withdraw the assignment?

# Allowed I outcomes

Use only these experimental I outcomes:

## POSITION ESTABLISHED / FUNCTION ESTABLISHED

A materially relevant observer position exists and a selective function meets canonical v4.1 requirements.

## POSITION ESTABLISHED / FUNCTION UNRESOLVED

A materially relevant observer position exists, but available evidence does not establish the selective function.

## POSITION ESTABLISHED / I-FUNCTION NOT REQUIRED

The position is analytically useful, but O + V adequately reconstruct the relevant continuation without an additional I-function.

## POSITION UNRESOLVED

The supplied evidence does not justify establishing the observer position.

## NO MATERIAL I-POSITION ESTABLISHED

No observer position within the stated scope survives the remove-and-compare test.

Do not force an I-position into the reconstruction.

# Cross-position analysis

Where multiple positions remain:

Ask:

- what is visible to I₁ but not I₂?
- what is accessible to I₂ but not I₁?
- where do positions participate in different V-relations?
- where do positions inhabit different practical possibility fields?
- where is disagreement explained by different access rather than contradictory reality claims?
- where is information outside view?
- which exclusions are structural?
- which exclusions are selective?
- which exclusions remain unresolved?
- can one position alter another position's O, V, access, or visibility?

Do not average situated differences away.

---

# What stays outside view?

This section is mandatory.

State explicitly:

1. what no retained I-position can currently access;
2. what is unavailable because of the chosen system boundary;
3. what is merely unknown because evidence is missing;
4. what is structurally inaccessible if established;
5. what would require another I-position, another scale, or another source base to become visible.

Do not characterize an unknown beyond the evidence.

---

# Synthesis

Produce the smallest supported synthesis.

State separately:

### O
What structured possibilities matter?

### V
What relations are actually instantiated?

### I-positions
Which observer positions materially alter access, visibility, relevance, or exclusion?

### I-functions
Which selective functions are established, unresolved, or unnecessary?

### Outside view
What remains unavailable, invisible, untested, or outside the chosen boundary?

Do not convert positional difference into selective causation.

Do not convert absence of access into absence of existence.

Do not convert unexplained structure into I.

---

# Test criteria

This experimental protocol succeeds only if it improves analysis without degrading canonical safeguards.

Evaluate each run for:

1. **Position gain**
   - Did explicit I-positions reveal analytically relevant information absent from the v4.1 baseline?

2. **Blind-spot gain**
   - Did the protocol clarify what remained outside view?

3. **Selectivity discipline**
   - Were I-functions still withheld unless canonical evidence requirements were met?

4. **Anti-proliferation**
   - Were unnecessary positions removed?

5. **O/V integrity**
   - Did observer-position modelling avoid contaminating O and V?

6. **Unknown discipline**
   - Did missing access remain distinct from non-existence?
   - Did missing knowledge remain distinct from structural openness?

7. **Cross-domain robustness**
   - Does the protocol remain useful across social, organisational, technical, biological, physical, and conceptual cases?

8. **Reproducibility**
   - Do different models identify materially similar positions and function statuses?

---

# Comparison requirement

For test cases, compare against canonical v4.1 using the same input and scope.

Do not judge success by whether the experimental protocol finds more I.

Judge success by whether it reveals more supported positional structure while preserving or improving epistemic discipline.

A richer result is not automatically a better result.

# Non-claims

This protocol does not establish:

- that every system has an observer;
- that observation requires consciousness;
- that every observer carries a selective function;
- that every position is I;
- that physical interaction alone establishes an observer position;
- that access establishes existence;
- that lack of access establishes non-existence;
- that positionality implies agency;
- that I is ontologically fundamental.

This is an experimental analytical distinction only.
