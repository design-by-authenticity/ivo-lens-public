## Evidence limits

This publication archives supplied results; no tests were rerun for this archival change. Raw case inputs, full baseline/v0.1/v0.2 outputs, model identities and versions, execution settings, run dates, and independent scoring were not supplied with these four files. Reproducibility and the reported comparative gains cannot therefore be independently verified from this archive alone. The v0.1 test history is described in the v0.2 change note, but its underlying run records are not included.

These cases mainly test restraint against false-positive I-function assignments. They do not establish reliable recognition of evidenced I-functions, general validity, or cross-model robustness.

## Recorded checkpoint and next phase

The supplied summary recommends retaining v0.2 unchanged pending positive-I cases, with particular attention to false negatives. Candidate domains are algorithmic selection, traceable human choice, formal organisational decision rules, and technical systems with an independently traceable selective step. These are proposed tests, not executed results or pre-established I-functions.

Subsequent test results belong in a new dated record so this supplied preliminary summary remains an identifiable historical snapshot. Record exact inputs, outputs, model/settings, scope-matched comparisons, and selection evidence for that next phase.
